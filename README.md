# Дмитрий Козлов — личная страница

Небольшое резюме с тремя необязательными достижениями. Белая тема, HTML/CSS/JavaScript без сборки, серверного кода и фреймворков.

## Запуск

1. Откройте эту папку в VS Code и запустите `index.html` через Live Server.
2. Или выполните `python3 -m http.server 8000` из этой папки и откройте `http://localhost:8000`.
3. Для своей фотографии положите изображение `assets/profile.jpg`. Пока его нет, используется `assets/portrait-placeholder.svg`.
4. Для публикации скопируйте **содержимое** папки в корень репозитория `USERNAME.github.io` и выполните `git add . && git commit -m "Update portfolio" && git push`.
5. В GitHub Pages выберите публикацию из `main` и `/(root)`.

## Достижения

- «Скрытая личность» — стереть не менее 52% слоя над фотографией монеткой.
- «Астролог-аналитик» — вычислить MDS, затем перейти к X = 2004, Y = 2026.
- «Укротитель бобров» — продолжить последовательность 1, 6, 21, 107 значением 47 176 870.

Прогресс звёзд хранится в `localStorage` по ключу `dk-portfolio-achievements-v1`. Он сохраняется между перезагрузками страницы на том же адресе и в том же браузере. Процент частично стёртого слоя не сохраняется.

## MDS

Используется classical multidimensional scaling на синтетических 20 объектах с 8 признаками: стандартизация, матрица квадратов евклидовых расстояний, двойное центрирование и собственное разложение вращениями Якоби. Скрытая звезда — отдельный объект и не является MDS-точкой.
